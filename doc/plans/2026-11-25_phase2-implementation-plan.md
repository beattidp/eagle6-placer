# Phase 2 Implementation Plan — `eagle6-placer` (Coarse-to-Fine, Mirroring, Congestion & Candidate Ranking)

*Date: 2026-11-25*
*Baseline: `v0.1.1-phase1` (33 passing tests; local polish mode, soft overlap legalization, pour-net via tolerance, `--preview` with `tPlace`/`bPlace`).*

---

## Goals & Exit Criteria
Phase 2 expands `eagle6-placer` from a local keep-side placement polisher into a full coarse-to-fine PCB placement engine while preserving all core safety invariants (read-only `.brd`, `.scr`-only output, sacred `locked="yes"` anchors, zero code coupling with `eagle6-mcp` and `eagle6-freerouting`).

Phase 2 is complete when:
1. **`eagle6-placer place <board.brd>`** can take an unplaced or scattered board (components sitting outside the layer `20` outline, as freshly generated by EAGLE Schematic → Board) and produce a legal, low-crossing placement inside the board outline around locked anchors.
2. **`--allow-mirror`** supports safe Top ↔ Bottom side flips for unlocked SMD components and emits valid EAGLE v6.6.0 `MIRROR '<name>';` + `ROTATE =MR<angle> '<name>';` + `MOVE '<name>' (x y);` commands verified via `eagle6-mcp`'s `validate_edit_script`.
3. **Routing congestion penalty** prevents dense routing bottlenecks without sacrificing MST wirelength or crossing reductions.
4. **Multi-seed candidate generation (`--candidates K`)** and optional **closed-loop ranking** produce deterministic ranked candidates with clear JSON comparison summaries.
5. All unit, regression, and staged EAGLE v6.6.0 verification tests pass under `pytest`.

## Milestones

### Milestone 2.1: Routing Congestion Grid Term (`cost.py`)
**Objective:** Penalize local airwire/pin density hotspots that cause autorouter vias or unrouted channels.
- Add a configurable coarse 2D routing grid (`congestion_cell_mm`, default `2.5 mm`, `congestion_weight`, default `0.5`) to `CostConfig` and `RoutabilityEvaluator`.
- For each non-pour MST airwire edge, increment demand across grid cells intersected by the edge's bounding box (or Bresenham/DDA traversal); penalize excess demand above a cell capacity threshold (`max(0, demand - capacity)^2`).
- Report `congestion_penalty` in `CostBreakdown` and JSON metrics.
- **Tests (`tests/test_cost.py`):** Verify uniform spread scores strictly lower than a clustered bottleneck with equal MST wirelength.

### Milestone 2.2: Double-Sided Placement (`--allow-mirror`) (`optimizer.py`, `emitter.py`, `cli.py`)
**Objective:** Allow unlocked **SMD-only** components to flip between Top (`R*`) and Bottom (`MR*`) when explicitly opted in via `--allow-mirror`.
- **Constraint rules:**
  - THT components (`is_through_hole=True`) are never mirrored by default (they already occupy both sides and flipping THT parts changes assembly side unexpectedly unless forced).
  - Side-flip move operator (~10% move probability when `--allow-mirror` is enabled) toggles `pose.mirrored` while respecting bottom/top keepouts and same-side courtyards.
- **EAGLE v6.6.0 `.scr` Emission (`emitter.py`):**
  - Detect `side_changed = (new_pose.mirrored != init_pose.mirrored)`.
  - Emit `MIRROR '<name>';` **before** `ROTATE ={new_rot} '<name>';` and `MOVE '<name>' (x y);`.
  - **Critical Verification:** Dry-run a side-flip `.scr` (both `R* → MR*` and `MR* → R*`) in real CadSoft EAGLE v6.6.0 via `eagle6-mcp`'s `validate_edit_script` to confirm exact `rot` and `(x, y)` behavior (note: in EAGLE GUI `MIRROR` reflects coordinates unless `MOVE` follows—emitting `MOVE` after `MIRROR`/`ROTATE` guarantees exact final `(x, y)`!).
- **Tests:** Unit tests in `tests/test_optimizer.py` and `tests/test_emitter.py` + staged `eagle6-mcp` verification on `mixed_tht_keepout.brd`.

### Milestone 2.3: Coarse-to-Fine Placement Engine (`coarse.py`, `cli.py` `place` subcommand)
**Objective:** Handle boards where unlocked components start outside the board outline (fresh schematic-to-board) or are badly scattered.
- **Stage 1 — Force-Directed Analytical Placement (`ForceDirectedPlacer`):**
  - Model locked components as fixed anchors and unlocked components as movable nodes connected by weighted springs (clique or star net model, down-weighting pour nets and honoring `--proximity-group`).
  - Run damped iterative spring relaxation + gentle inter-component repulsion, clamping unlocked centroids into the safe inset board rectangle.
- **Stage 2 — Grid-Snapped Overlap Legalization (`OverlapLegalizer`):**
  - Place components in descending courtyard-area order (largest ICs first, smallest passives last) onto the nearest legal grid-snapped spiral position around their force-directed target, respecting locked anchors, holes, keepouts, and board outline.
- **Stage 3 — Fine Simulated Annealing Refinement:**
  - Feed the legalized coarse layout into `LocalPolishOptimizer` (with `--displacement-weight 0.0` by default in `place` mode since initial off-board positions are arbitrary).
- **Synthetic Fixture:** Add `tests/fixtures/unplaced_fresh.brd` (all unlocked parts lined up outside `x < 0` or `y < 0`, mimicking a brand-new EAGLE `.brd` created from `.sch`).
- **CLI Subcommand:** `eagle6-placer place <board.brd> [--steps 6000] [--allow-mirror] [--preview] ...`

### Milestone 2.4: Multi-Seed Candidate Exploration & Optional Closed-Loop Ranking (`candidates.py`, `cli.py`)
**Objective:** Escape single-seed local minima and optionally rank top-$K$ placements by real autorouting outcomes.
- Add `--candidates K` (default `1`) to both `polish` and `place`:
  - Runs `K` deterministic seeds (`seed`, `seed + 1`, ..., `seed + K - 1`), ranks by `(overlap_violations, total_cost)`, and emits the winning `.scr`/`.json`/preview (plus optional `--keep-all-candidates` to inspect runners-up).
- Add a clean, decoupled **candidate export manifest** (`candidates_manifest.json`) listing each candidate's `.scr` path and analytical metrics so an agent or shell workflow can pass the top-$K$ `.scr` files through `eagle6-mcp` + `eagle6-freerouting` (`route_board`) with **zero code coupling** between repos.

### Milestone 2.5: Documentation, Real-Board Benchmarks & `v0.2.0-phase2` Tag
- Update `doc/user-manual.md`, `README.md`, and `doc/specification.md`.
- Add `doc/features/03_phase2-coarse-mirror-congestion.md` and benchmark walkthrough in `doc/walkthroughs/` (including `unplaced_fresh.brd` and `prpp-mcu.brd` with `--candidates` / `--allow-mirror` comparison).
- Full `pytest -v` regression suite + staged EAGLE v6.6.0 verification + `v0.2.0-phase2` tag.
